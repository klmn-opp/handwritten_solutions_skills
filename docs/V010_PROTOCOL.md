## 连续数据审计后的有限原型协议

130条真实区域来源已核验：Train113（70英文词行、43数学区域），Validation17（11英文行、6数学区域）。
只有10条训练英文达到5词；新原型限完整英文词/短片段，不据此声称完整长句或数学生成可用。
预先固定短区域研究门槛60 Train、20多词、10 Validation、3 Train文档；实际70/41/11/5，允许有限试验。
未见字符包括Validation中的0/2/9。旧v0.9单字原型不继续更新。

`context-ink-region/1`直接解码完整64×512离线区域：个人字体渲染提供准确内容参考，
卷积编码器+沿行扩张卷积聚合邻近上下文，共享8维区域风格潜变量、词/多词角色条件。
整块真实图像监督，不切单字、不直接复制参考像素、不恢复笔顺。单作者数据不能证明跨作者风格分离。
保留原色裁剪；训练视图只做灰度墨迹提取、完整墨迹统一缩放与平移，记录变换。数学区域仅进语料审计。

固定种子1011，每臂800次AdamW更新，batch4，lr0.0003，固定最后一步，不以形状距离选最优：
1. context：上下文与共享潜变量开，每批3真实/1字体辅助，prior-support=0。
2. no-context：关闭沿行聚合，其他相同（局部卷积仍有局部感受野，不谎称完全无上下文）。
3. no-style：关闭共享潜变量输出通道，其他相同。
4. support：同context，但prior-support=0.05，约束采样先验到对应整块字体距离场。
5. half-real：同context，但2真实/2字体辅助。

五臂相同初始化规则和更新次数；真实/字体比例有意不同，support臂增加前向计算，所以不是等墙钟预算。
每200步保存权重/优化器/验证；最终全部冻结后评估，任一内容失败不选择发布。
若原型输出明显失败，不追加旧模型训练或无限收缩loss；记录失败并给No-Go。
新的区域Holdout来自phy1此前未用页，仍属于已曝光的旧留出文档，fresh_document=false。
在五臂冻结前不打开转写/图像，后续不凭该留出调参。没有全新文档级最终泛化结论。
