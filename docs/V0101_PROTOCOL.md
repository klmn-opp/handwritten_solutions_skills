# v0.10.1 对齐与内容学习试验协议

基于f25d35b，新分支experiment/context-alignment-v0101。用户授权继续上一轮提出的训练计划。
生产CPU、Profile/latest、全部旧run不改。所有新实验独立run，私有数据和checkpoint不进Git。

1. 先冻结v010主模型，用同一70Train/11Val分别测后验重建与条件先验生成，零更新。
2. 用旧Train固定16单词+16最短多词区域，随机初始化同架构2000次更新，检查小集学习能力；
   这只是故障诊断，不当泛化或可发布模型。固定seed1101，batch4，lr.0003，16词由seed无放回选择。
3. Sol xhigh补Train完整词组/行与AS Validation，phy1新未用区域另封；不强切连笔、不修补墨迹、
   不确定或污染直接排除。机械校验来源300DPI像素、bbox、SHA和固定split。
4. 无全新文档可用；新phy1区域仍fresh_document=false，全部候选冻结前不读新标签/图像。
5. 按诊断选择有界对齐/内容约束路线，先固定规则再运行；不是延长旧CVAE即算机制修复。
6. 内容评估与作者风格分离；冻结识别器可作训练约束，但其得分不作为独立成功证据，
   必须另有Tesseract/盲转写/原图。字体参考是辅助，生成输出不能回标成真实数据。

## 零更新/小集诊断后的固定比较

旧模型Train后验形状.242/先验.227、Val .326/.313，两条路径均差；32区2000更新后
小集.0466/.0467，但Val .4056/.4061。网络能学习小集，无法据此证明泛化；不把问题仅归因先验。
下一步固定以下机制比较，不读取新Holdout：

- 使用14.5万参数确定性完整区域解码器，保留沿行上下文，训练与推理同一路径；本轮不宣称学到随机风格变化。
- 自然空白间隙可靠时，按完整词统一尺度放入参考词槽。只派生训练视图，保留原300DPI图、坐标和变换；
  不分离连笔字符、不补墨迹。标准化后的词间距由参考布局控制，不能说学习了自由行节奏。
- 1–6词范围内、明确空白/词宽关系的Train子集供三臂共同使用。不可靠对齐显式拒绝用于像素监督；
  全部英文Val仍评估，不按可对齐与否选择好看的样本。
- 先1500步字体辅助预热（不是个人真实训练），再从同一预热权重启动三臂：raw/aligned/aligned-content。
  各2000次更新，batch4每批3真实+1字体，lr.0003，seed1103；固定最后一步，全候选冻结。
- aligned-content每4步对前2个真实样本增加.15×冻结TrOCR转写交叉熵；TrOCR权重不更新，
  已验证输入梯度非零、教师梯度为空，约1.65GB分配显存。身份约束识别器不能再算独立评测者。
- 校验源、checkpoint/优化器/RNG/曲线/实际参数变化。最终Tesseract+独立Sol盲转写与实际图像为内容证据；
  TrOCR分数只作与训练教师有关的诊断。不凭训练loss降低、字体复制或记住训练词宣布成功。
