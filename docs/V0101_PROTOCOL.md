# v0.10.1 对齐与内容学习试验协议

基于f25d35b，新分支experiment/context-alignment-v0101。用户授权继续上一轮提出的训练计划。
生产CPU、Profile/latest、全部旧run不改。所有新实验独立run，私有数据和checkpoint不进Git。

1. 先冻结v010主模型，用同一70Train/11Val分别测后验重建与条件先验生成，零更新。
2. 用旧Train固定16单词+16最短多词区域，随机初始化同架构2000次更新，检查小集学习能力；
   这只是故障诊断，不当泛化或可发布模型。固定seed1101，batch4，lr.0003，16词由seed无放回选择。
3. Sol xhigh补Train完整词组/行与AS Validation，phy1新未用区域另封；不强切连笔、不修补墨迹、
   不确定或污染直接排除。机械校验来源300DPI像素、bbox、SHA和固定split。
4. 无全新文档可用；新phy1区域仍fresh_document=false，全部候选冻结前不读新标签/图像。
5. 按诊断选择有界对齐/内容约束路线，先固定规则再运行；不是延长旧CVAE即算机制修复。
6. 内容评估与作者风格分离；冻结识别器可作训练约束，但其得分不作为独立成功证据，
   必须另有Tesseract/盲转写/原图。字体参考是辅助，生成输出不能回标成真实数据。
