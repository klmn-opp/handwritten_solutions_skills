# v0.10.4 自主训练循环与窄带轮廓诊断

用户授权持续训练、验收、总结并进入后续轮次，直到达标或具体需要作者手动工作。
任何时刻不修改正式CPU/Profile/latest；旧留出仅历史证据，不用来调目标或选checkpoint。

本次先做A轮，不预先宣称方案有效。冻结mass起点，同一24条真实Train，16词+8最短词组，
过滤已准入、唯一字串、长度3–32，固定seed1401。两臂各1200更新、AdamW1e-4、batch4，
只训练真实样本，无字体输出辅助、无识别教师。输入仍为精确文本对应的个人字体参考。
24样本拟合能力是有意的记忆诊断，不是泛化或新风格证明。

目标使用原扫描对齐墨迹>.5轮廓的距离场栅格，保存原图，不修补涂改，不制造新样本。
目标为.5距离L1（边界加权）+.5前景加权墨迹MSE+.5Dice。

- soft：原sigmoid距离到墨迹转换。
- projected：先将模型零等值轮廓重新计算空间距离，以固定0.35像素过渡生成墨迹；
  训练前向与推理一致，反向用原soft路径直通近似，梯度有偏，应明确记载。
  投影本身没有参数，不用字体像素回填，不更改轮廓内外标签；空白/实心正确处理。

每臂保存零更新图、400/800/1200权重/优化器/RNG/曲线及源码摘要。
旧mass+projected的零更新图必须作为独立对照；不能把投影去灰本身叫神经训练收益。
投影会删除旧预测<.5的淡笔，因此必须独立检查字形内容，不能只按灰墨下降判成功。

A轮若至少一臂Train二值Dice>=.80且相比起点增加>=.20、无空白输出，说明有限拟合能力可用；
否则转向分辨率/对齐/架构诊断，不直接扩大相同训练。通过也不能发表生产质量结论。
B轮方案要根据A轮记录后再固定，使用开发集验证与独立内容观察；不读取旧留出来指导调整。
原171真实Train仅8条>=5词、真实连续书写支持有限；不把短词拟合叫完成长句泛化。

自动门禁按内容/灰影/细笔/碰撞分开记录。新的候选经过开发内容和清晰度验证之后，
需要作者判断“像本人”和新文档独立测试；这时才提出具体手动要求，不通过反复训练回避。
不做RL、外部扩散模型或未经验证发布。持续迭代每轮都保留失败、版本与真实训练证据。
