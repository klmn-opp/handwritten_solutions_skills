## 固定墨迹的排版修正

按真实词中的字形框和主体高度估计比例。14 个有效 t 的中位相对高度为 1.22，原排版框为 1.50。
按已冻结阈值收小过高 t，并保留底边及宽高比。l、r 的间距分布各自只有 10、6 个可靠相邻字母对，
只收窄明显过宽的内间隙。保留词锚点的一臂在 64 个实际词句输出中取得以下中位变化，单位为
渲染的小写主体高。

| 实际墨迹指标 | 修正前 | 修正后 |
| --- | ---: | ---: |
| t 高度 | 1.49 | 1.35 |
| l 前词内空隙 | 0.66 | 0.29 |
| r 后词内空隙 | 0.34 | 0.22 |
| 词与词之间空隙 | 0.74 | 0.78 |

此臂 0 空字、0 边缘裁切、0 新增相邻重叠像素。另一臂的实际词间空隙中位为 0.70，新增 2 个
相邻重叠像素，混排使用保留词锚点方案。两臂合计 128 份坐标、连续墨迹与 PNG 精确重放。
这项改进属于排版校准，神经权重保持冻结。现有 r 右、l 左样本量有限，结果仍需随着更多样本复测。

## 神经训练与判定

| 路线 | 本阶段真实更新 | 自验结果 |
| --- | ---: | --- |
| 13 词空间修正 | 1,000 | Train Dice 0.927→0.933，邻字被移除后变化远小于整体修正，主要表现为锐度变化 |
| 分层词/字先验，有/无邻字 | 各 2,000 | 生成无需逐次外部参考图，f 仍出现明显缺墨，带邻字的优化验证 Dice 较低 |
| 修正有效轴后，冻结与联合解码对照 | 各 1,000 | 联合训练改善训练重建，固定开发词中的断笔仍存在。零轴修正只是必要的坐标约束 |
| 局部 PCA 风格去噪先验 | 2,500 | `from` 的部分输出更完整，r/w/t 等还有断笔或变形，1 个局部 t 触及图边 |

总计 9,500 次优化步骤，来自六个实验，成对候选分别训练。最后的去噪先验更新了自己的参数，使用
60 个来源词中的已核验局部样本，8 组用于观察优化验证。它从文字和正态噪声生成风格，不查找训练中心。
冻结墨迹解码器和 PCA 已见过优化验证源，评测词句也已暴露。352 份输出全部精确重放。

去噪后 f 的八图都有不同二值像素，其与真实样本的最小差异像素中位从 63 增到 269，成对差异中位从
850.5 降至 657.5。像素差异只能描述形态，断笔也会增加差异。可见失败保存在 `comparisons/denoised-prior.pdf`。
没有足够证据判定该路线学到了更稳定的个人风格，暂停在同一局部数据上增加步数。
