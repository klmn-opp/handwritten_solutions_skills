# v0.10.19：监督与生成条件的一致性

v18全部九模型、18子run和主run冻结。本阶段继承215项历史/默认保护，C不读，生产CPU、
personal@v1、正式latest不变。只在独立实验分支，Torch仍限隔离环境。

v18固定权重诊断显示：同一f/t解码器对已见联合形态条件附近的采样较清楚，独立高斯组合
易有灰芯、双边。这里只说明条件区域值得检验，不能把统计采样称神经训练或新自然风格。

首个有限对照：从v18关闭邻字的f/t 8000检查点恢复网络、词码、优化器、全部RNG，追加4000
真实CUDA更新，与v18已冻结的同源继续4000组比较。真实19目标、字体教师、核心采样、学习率
及预算一致；只替换真实先验支持的条件分布与配对目标：每类从已学联合10维条件中心均匀
抽一个，添加该类逐维标准差乘0.15的高斯扰动，直接监督该中心对应的真实墨迹。
不再由生成图反向挑“最接近的观测”作为该先验的目标。中心和尺度停止梯度，真实训练码
仍在真实重建项学习；生成也使用相同邻域分布。单样本类或无变化坐标不人为添加变化。

训练不新增合成目标，不修补原图，不更改标签。网络输出来自实际参数学习，不检索位图。
但每次采样依托一个已见训练形态中心，必须显式报告，不能虚称完全未见风格；需要检查
最近Train距离、二值同形、潜变量变化和内容。Gaussian条件扰动本身不是新神经训练。

这些10维联合条件逐字采样，生成时前两维不再保证整词共享；全局作者参数仍共享。
这是稳定局部组件，**不是上下文整句模型**。f/t容量模型其他70类仍是字体教师辅助。
若基本内容和缺墨改善，再决定全29真实类预算，不能用小集成功替代完整词句验收。
