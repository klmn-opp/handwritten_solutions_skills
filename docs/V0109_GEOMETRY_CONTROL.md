# v0109 有限数据/步数对照补充协议

在新直接墨迹去噪原型累计3000更新后，容量Dice0.267，仍明显缺笔，没有通过V0109_PROTOCOL门禁。
因此停止扩大该原型，不能将其放入可读作业或放宽原门槛。613条扩充数据保持prepared，不凭数量声称新墨迹目标完成。

用户本轮明确要求增加当前可读模型的数据及训练，并已认可v0108视觉修复。为直接检验这一建议，另设以下有限对照；它不是替代上述失败结论的自由新墨迹模型：

- 两臂均从同一v0107 stochastic checkpoint开始，优化器显式重置，seed1909、lr0.0002、各3000真实更新。
- A使用原512词中的373准入Train；B使用613条（553Train、60旧开发）的同规则无折叠配准准入Train。配准240次数值优化不算神经训练。
- B的新增101视图包括90个审核词/短片段/数字和11个无旧词墨迹重叠的f；所有原split保持，C不开。
- 保持同一网络、损失和推理种子1708–1711、v0108单次源轮廓采样与几何约束。仅数据差异是两臂之间的实验变量，训练集准入数量实际报告。
- 同时保留未继续训练的v0108基线，从而分开“继续训练”与“新增数据”两个问题。只作有限控制，不继续扩展同一几何CVAE或声称学习了新笔画拓扑。
- 所有候选先冻结再做开发和困难页面检查；内容失败必须回退并报告，不能按开发图挑checkpoint或按形状距离宣称自然度改善。
- 新编复杂题仅测试，不进入训练。几何模型仍按词处理，公式字形/结构由Handnote保留，长段落由原排版组合；不称端到端整段生成。

补充协议在两臂开始前固定。直接墨迹原型失败权重、优化器、曲线和图像全部保留。最终报告需分别写清两种模型、数据数量、真实更新与未解决的f形态上限。
