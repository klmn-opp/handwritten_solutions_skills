# v0.10.7 预注册：词内配准与条件风格可行性

作者已确认8候选内容正确，但新整词模型平均自然度/相似性2.5，Handnote及未训练旋转4.0。
暂停v0106直接距离场整词生成，不扩大其词表/步数；新实验不承担自由新墨迹生成的成功宣称。

1. 固定v0106经过逐词审查的512真实词（452Train/60已曝光开发），原件及划分不变，C禁入。
2. 首先优化每对Handnote/真实词的平滑取样场，学习的是对应关系，不更改真实词图；这是数值配准而非生成网络训练。
   2×5×17控制网格、横向64px/纵向24px上界、240步Adam，8/4/2尺度墨迹目标，平滑/折叠约束。
   零场恒等和真实目标辅助配准只作为诊断；目标辅助结果不能当文本生成。
3. 配准准入：无负Jacobian，边界无新增核心墨迹，Dice较恒等提高至少0.03，最终Dice≥0.35。
   条件风格模型仅用准入Train，最少64词、20种标签；若不足则停止。不以开发指标放宽门禁。
4. 两个等预算1000步神经模型：条件确定性均值、4维整词latent的条件VAE。
   监督是Train真实词配准场；内容条件为原Handnote词图与字符编码；prior受内容条件控制。
   不加新像素回归/字体距离目标，不把配准优化或字体随机变换计为神经训练。
5. 两模型冻结后在全部60旧开发及前12准入Train生成：均值一份，VAE四固定种子1708–1711。
   输出只取样原连续字体墨迹，没有负浓度修正、没有新笔顺、不能生成字体没有的连线/新拓扑。
   内容/折叠/裁边失败保留原输出；显式回退仅为独立预览，不算模型成功。
6. 报告真实更新、权重/优化器、运行资源、确定性重放、训练最近邻、多样性和字体差异。
   固定12开发词×基线/均值/两prior盲检，再按实际内容结果决定是否需要作者风格比较。
   只在内容合格而风格有待作者确认时停在人工节点，不开启C、不发布、不修改默认Profile/latest。

本轮主要问题：可学习的词内变化能否保持内容和清晰墨迹。即使通过，也不是整句生成或克服字体拓扑限制。
