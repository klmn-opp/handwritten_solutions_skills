## 固定数据、候选与预算

使用v0109已准备613真实视图（553Train/60旧开发），训练容量样本严格复用旧24条/19标签索引，不额外挑容易样本。原文档split不变，C不得读图/识别/训练。旧开发已曝光，不冒充新Holdout。

1. 零更新诊断：冻结旧v0109直接去噪3000步checkpoint，在t=0/0.1/0.5/0.9/1分别检查反推干净目标的误差及内容，记录前景/背景损失、64/128步采样；含目标的加噪重建必须标oracle，不能称生成。
2. 真实墨迹编码/重建器：固定24Train、2000次AdamW更新，batch8、lr0.001、seed2011。8×16×64空间码，无输入到输出的跳接；监督仅真实灰度墨迹，前景平衡BCE+softDice，不向字体轮廓加损失。此阶段是神经参数训练，但输出重建依赖实际目标图，绝非任意文字生成。
3. 只有Train平均二值Dice>=0.90、无空白且内容未见严重缺损，才训练条件生成器。编码器/解码器冻结，预测标准化空间码；文字token和字体图的编码仅作条件，无字体输出复制/变形旁路。固定3000次更新，batch8、lr0.0003、seed2011；10%纯噪声端点，真实前景加权v目标及冻结解码器的真实墨迹重建辅助。推理seed2012/2013，64逆步，绝不读取目标图。
4. 冻结后，同一固定前12容量词×2种子进行Sol匿名内容辨读。平均Dice>=0.45、无空白、>=20/24完整可辨才扩大。若12–19/24且无严重缺损，可作一次同目标额外3000更新，否则停止原型，不无限增加步数。
5. 扩充只有上一门槛通过才开始：553Train、最多每8样本一个真实辅助单字。容量编码器warmstart追加2000重建更新，冻结后新空间码条件生成3000更新。旧60开发仅在候选冻结后评估，内容>=90%且无严重缺损才考虑后续，不自动发布。

上述预算是真实optimizer更新；数学根号、数值诊断、OCR/HTR推理、图片整理都不计训练。全过程保存初始权重、checkpoint、优化器、RNG、曲线、训练与数据commit/hash、依赖、GPU/显存/耗时。

## 假设与可证伪性

旧SDF逐像素去噪在24词容量上都失败，不能仅归因于数据量。待检验假设：背景占比、细笔空间表示和高噪声内容条件共同限制生成。
先独立验证墨迹能被小型空间码忠实重建；重建通过而生成失败，则问题仍在条件分布/优化或样本覆盖，不能把重建成功称为生成成功。
本轮设计同时改变表示和目标，只能检验这条路线可行性，不能据此对单一改动做因果归因。小集成功不证明未见词泛化、多样性自然或个人风格优于Handnote。
保留字体基线、真实参考、旧失败模型和新失败图；相同文词/种子调度。不使用OCR教师或合成标签，不恢复DiffBrush/DiffusionPen/DiffInk，不做RL。
