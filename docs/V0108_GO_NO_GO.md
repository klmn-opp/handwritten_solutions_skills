## 原因、改动及边界

1. **多次低分辨率采样。** 旧路径包括字体栅格化、词图归一化、神经坐标采样、整句还原。新路径在相同个人矢量轮廓的4倍分辨率参考上合成坐标映射，一次采样到目标画布，再做面积抗锯齿。72词的原300DPI归一化参考与旧数据逐像素相同，4句原始参考也相同；未更换字形来制造优势。
2. **无折叠不等于自然。** 旧字段横向局部导数范围0.483–2.463，仍允许很强的局部挤压和拉伸。新约束平滑导数、限制到0.8–1.25、固定总宽，同时限制纵向倍率与剪切。这些是逆采样坐标导数，不能直接解释为字高或笔画宽度倍率。
3. **坐标与边界。** 使用实际取整后的缩放宽高和像素中心；词图预留64×32归一化像素，整句按词源窗口采样，避免复制邻词墨迹。没有阈值补墨、闭运算、填孔或合成修补真实扫描。
4. **几何方法的能力上限。** 模型仍在采样已有个人字体墨迹，只学词内形变，不能创造真实新连笔或新笔画连接。约束后位移RMS平均保留原来的81.36%（范围51.93%–98.75%）；变化未归零，但约束确实削弱部分变化，不能据此宣称解决字体趋同。

本轮固定72词（60已曝光开发词、12 Train），mean一个种子、stochastic四种子，每个控制场生成3种输出，共1080候选，另有72个Handnote对照。句子仍为4条已曝光训练句，保持内容、原字形、词位置及字体输出尺度一致；不冒充新的独立测试。
