# v0.10.23 词间节奏的首个有限实验

使用 v0.10.22 登记的 39 行和 110 对真实相邻词。以每对左右词的平均实际墨迹高度为单位，
逐文档留出，比较训练集全局中位数和使用词长、标点、大写与相邻词高差的有正则线性模型。
全程采用已核验的真实坐标，使用绝对误差和按文档平均的绝对误差评估。固定文档分组、
特征、正则和拟合方法。模型至少降低 5% 的等文档权重误差，且任意有至少 10 对的留出
文档误差上升不得超过 10%，才考虑使用它改变一组新实验页面的词距。

本项拟合统计几何参数。完整词图及行保留原样，字形生成模型的权重冻结。
原文档已在历史研发中使用，只有当前词距拟合按文档隔离。封存的 C 不参与。

按文档比较的拟合没有通过，采用真实词距分布的下四分位数，作为偏紧词缝的修正参考。
同一英文文本段从左向右，词距增加量取到目标差的一半，同时限制为局部平均词高的 15%。
整段可因页边、固定字形或碰撞减半，无法安全移动则沿用原位置。公式、回退词和换行是分段边界。
仍以四题相同模型生成结果为底稿，逐字墨迹像素与种子完全复用，仅改变整词 x 坐标。
验证四页数学像素、逐词落位、词距分布和内容，保留同页前后 PDF 与逐页 PNG。
