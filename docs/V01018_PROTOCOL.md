# v0.10.18 可靠局部真实墨迹诊断

v17四模型与全部证据冻结。独立分支继续，正式CPU/Profile/latest、全部历史与C不变。
本阶段目的是排除完整词估计框的监督冲突，不能以单字成功替代上下文模型验收。

数据只用已核验的259个字形视图及新24框（含两个f），原始整词全部保留。
每个局部视图保留原文档/页/词/坐标/审核/摘要。Train词哈希共享词级码，
每字身份和左右邻字条件明确。不使用未验证位置、共享笔画裁剪、补笔、C或新公开数据。
框内墨迹按现有支持库规范映射到96画布中央64，仅为训练坐标归一化，不称原始形状无变换。

有限训练：从已冻结24k字体辅助语义场开始，AutoDecodedSemanticInk共享作者参数、
字符/邻字条件、2维词级码；8000新CUDA更新，seed3518，模型lr.0001、码lr.001、
L2 .01。每步4个真实局部图，类别均匀、类内样本均匀；每图1024空间查询，
75%中央80区域、25%全图。BCE加权1+3×ink，SDF辅助.2。
同上阶段保留先验内容约束.5：每步2个真实类取完整观测最小BCE、2个未覆盖类
由冻结字体教师监督。先验码来自当前Train词码拟合高斯（均值/协方差停止梯度），
不从开发图估计。不得宣称完全没有字体辅助。

每1000步保存网络、词码、优化器、采样/RNG，最终8000为本轮候选；不按开发图反复挑checkpoint。
明确分开：283图对应训练码重建；29类多个随机码的无目标局部生成；固定24个旧开发词
双seed无目标组合生成。生成时不输入目标图、对应训练码、对应目标框或字体轮廓。
布局仍用冻结Handnote坐标与旧Train尺度统计。没有新独立Holdout，C保持封存。

先观察是否仍有灰芯、缺墨、错字和明显变形。通过基本门禁后才生成完整英文行与混合数学
页面并请求本人风格判断；不合格时依据重建/先验差异定位下一因素，不无限堆步数。
即使通过局部内容，也只是可学习的局部组件，不是端到端连续书写或自然度自动达标。

## 第二臂：分离共享词条件与局部字形变化

首臂8000完成，f/i/t的Train重建平均Dice约.417/.544/.511，单例A/F/H约.91；
随机先验仍明显灰芯。词码协方差特征值.00030/.15797，实际近一维，不能称随机变量完全无效。
由于Train重建本身失败，不将问题只归咎于新词布局或先验抽样，不直接增加旧配置步数。

新臂相同283原图/标签、相同24k初始化、相同词码初值、相同8000预算和损失，新增8维
局部形态条件，与2维词级条件分开。局部条件由Train墨迹减每字符均值后作共享PCA8，
代码固定；每类条件高斯只来自该类Train。PCA是统计准备，不算神经训练；生成网络
不会调用PCA逆变换，不接收或检索目标图。局部条件也不是已被验证的独立个人风格因素。

HierarchicalSemanticInk将每token的word2+local8分别投影到16维作者表示，网络字段
仍实际训练。生成全词时word2共享、local8逐字符采样；单例类别不宣称学到真实变体。
字体教师仅用于缺真实覆盖类别，局部码置零。词码/模型初始化沿用对照初值，
新增局部投影std.02；字符/空间采样保持同seed，新增局部采样使用记录的Torch RNG。
最终8seed单字与2seed词图均保留，局部生成seed偏移100000，词组合偏移200000。
首臂所有失败图、权重与优化器不变；未通过内容门禁前不要求作者评分。
