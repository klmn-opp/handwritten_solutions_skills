# v0.10.15 语义布局到个人墨迹

承接作者自主迭代授权。v01014全部封存，本阶段独立分支；正式CPU、personal@v1、latest、封存C不变。上一轮证明：真实监督的局部网络能保留文字，但仍依赖字体图像，真实配对会出现灰影；减少配对监督又主要返回字体。不能据此简单归因样本少，亦不继续相同损失/步数搜索。

第一项实验移除生成器输入中的字体像素和轮廓。仅保留准确ASCII字符身份、前后字符身份、Handnote提供的字形包围框/布局坐标。共享神经坐标场预测墨迹和辅助距离场；统一学习的writer参数不从本次参考图片抽取。最近两个字符场允许重叠，保留上下伸结构。它是确定性的局部语义墨迹组件，不是端到端连续整行生成，也没有随机潜变量。位置仍来自Handnote，不能宣称完全独立排版或已学习自然变化。

先进行内容能力预训练：personal@v1主字形的实际Handnote输出作为明确标识的字体辅助目标，不称新增真实扫描。使用固定、排除旧开发/新词完整字符串的辅助文本，固定6000次AdamW更新、seed3015、lr.0005、batch4、每图2048查询点；学习加权墨迹BCE及.2距离场L1。训练目标只用于监督/训练采样，不进入推理。初始化和最后模型、优化器、RNG、采样计数、硬件、源码均留档。最后checkpoint固定冻结，测试旧开发/未训练提示词和完整句子，不按中途loss选择最好版本。

内容门禁：24旧开发/提示词至少22条准确完整、无严重空白/裁切；4句必须逐句内容完整才有资格进入整页。这些是反复使用的开发检查，不是新Holdout。若通过，下一实验再登记实际真实监督配置；不得凭字体辅助模型清楚即称本人历史笔迹学习成功。若失败，保留失败，根据可测机制调整，不要求作者重复授权。

## 字形杂纹诊断，两项有限消融

首轮6000更新、50578参数、参数L1变化3979，36图无空白/边界越界，但f/s/g等含杂纹、断续，未达到可供作者验收的质量。平均到字体Dice .8398不是质量通过证据。

原采样半数只在前景、半数在整张图，会相对少观察细窄字形周围的负样本；同时原字体主字形不随邻字符变化，邻字符embedding却可参与形状预测。以上是待检验机制，不能直接当作已证实原因。

冻结首轮后，两臂各从同seed随机初始化6000更新，其余同原配置。local-sampling把前景抽样改为按字符均匀选择、包围框中心半径1.6范围均匀坐标（另一半仍整图）；identity-capacity使用完全相同新采样，但将邻字符条件乘0，测试基础字符身份与位置是否足够。零邻接臂必须明确不具备上下文形状学习；二者均不属于真实扫描训练。固定最后模型，仍同24词内容检查，失败原图全部保留，不比较训练loss来代替可见验收。

## 坐标频率诊断

两臂均6000冻结，无空白/边缘越界，采样改动减轻杂纹，但关闭邻接没有明显改善。直接把Train字体f/g/R的墨迹按其框归一化，逐图看到轮廓一致（f11、g13、R8次，同字形ID）；没有证据表明这些噪纹来自真实扫描标签错乱，因为当前尚未用扫描训练。

观察到窄笔画有高频横向杂纹，新增一次smooth-identity单因素实验：与identity-capacity相同随机初始化、数据、采样、6000更新，只把坐标Fourier频率4和8通道固定为0（保留原始xy和频率1/2）。不进行图像滤波或事后修补，也不把去除高频通道本身称训练成功。冻结后看完整输出，继续保留原失败候选。

## 一次有上限的内容容量延长

平滑坐标确实去掉细碎纹理，但f/R等仍错误、轮廓更圆钝，Dice .8299，并未解决字符身份。原频率身份臂每1000步均值loss从.5309持续降至.2448，最近两段.2600→.2448，尚无收敛证据。不能用loss下降当质量成功，但它支持一次有上限的容量排查。

因此只延长identity-capacity：从6000步完整恢复参数/优化器/NumPy和Torch RNG，追加18000步到24000，其他配置不变；固定最终权重。保留所有1000步快照，但不从中挑最好图片。本次是新架构的有限内容容量测试，不是继续旧CVAE。若仍有明显杂纹，不再原配置追加；下一因素需从实际误差定位。这里仍是字体辅助学习、无真实扫描、无随机个人变化。
