# v0.10.15 语义布局到个人墨迹

承接作者自主迭代授权。v01014全部封存，本阶段独立分支；正式CPU、personal@v1、latest、封存C不变。上一轮证明：真实监督的局部网络能保留文字，但仍依赖字体图像，真实配对会出现灰影；减少配对监督又主要返回字体。不能据此简单归因样本少，亦不继续相同损失/步数搜索。

第一项实验移除生成器输入中的字体像素和轮廓。仅保留准确ASCII字符身份、前后字符身份、Handnote提供的字形包围框/布局坐标。共享神经坐标场预测墨迹和辅助距离场；统一学习的writer参数不从本次参考图片抽取。最近两个字符场允许重叠，保留上下伸结构。它是确定性的局部语义墨迹组件，不是端到端连续整行生成，也没有随机潜变量。位置仍来自Handnote，不能宣称完全独立排版或已学习自然变化。

先进行内容能力预训练：personal@v1主字形的实际Handnote输出作为明确标识的字体辅助目标，不称新增真实扫描。使用固定、排除旧开发/新词完整字符串的辅助文本，固定6000次AdamW更新、seed3015、lr.0005、batch4、每图2048查询点；学习加权墨迹BCE及.2距离场L1。训练目标只用于监督/训练采样，不进入推理。初始化和最后模型、优化器、RNG、采样计数、硬件、源码均留档。最后checkpoint固定冻结，测试旧开发/未训练提示词和完整句子，不按中途loss选择最好版本。

内容门禁：24旧开发/提示词至少22条准确完整、无严重空白/裁切；4句必须逐句内容完整才有资格进入整页。这些是反复使用的开发检查，不是新Holdout。若通过，下一实验再登记实际真实监督配置；不得凭字体辅助模型清楚即称本人历史笔迹学习成功。若失败，保留失败，根据可测机制调整，不要求作者重复授权。
