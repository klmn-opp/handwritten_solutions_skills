## 原因及下一步

1. **监督目标错位风险是首要技术问题。** 同一文字的字体图与真实扫描只作整块包围盒对齐；
   自然单词间距、基线、字宽不同，逐像素SDF/BCE/Dice会把不同位置的笔画平均成墨团。
   这是结合训练目标与图像的解释，尚未经专门对齐消融证明，不能称唯一原因。
2. 当前没有独立可微文字身份约束；结构参考不足以保证解码后每个字母存在。加入support虽改善部分转写，
   也重新带来字体锚定风险，不能无限加权收缩回字体。
3. 70 Train中29单词、41短片段，仅10长片段；验证长度和字符分布偏移明显，完整句子的监督确实不足。
   但增加同样数据/训练步数不能自动修复监督错位。不是结论“已有PDF不够”。
4. 下一小阶段先在现有Train文档采集完整、清晰英文词组/行，目标100–300条多样片段作为数据工程里程碑，
   不是保证训练成功的最低数量；保留连笔、不强切字符。评估可靠词级/软单调对齐和冻结识别器内容约束，
   用开发数据比较后再固定新协议；不对已看Holdout继续调参。
5. 只有文字准确、自然变化和作者偏好均通过，才评估扩大训练或SFT；目前没有RL基础。
