## 训练做了什么

[预登记协议](V01013_PROTOCOL.md)在参数训练前提交。没有恢复第三方模型路线，未添加新识别标签，未打开封存C。

1. 从已有613视图选取2–18字符、ASCII纯英文的450 Train和58旧文档开发样本。450裁剪摘要各不相同，来自8个Train文档；282种词中211种只有1份真实写法。未强拆自然连笔、未修补遮挡墨迹。历史开发文档与Train分离，但已曝光，不能称全新Holdout。
2. 保持原墨迹编码器冻结，仅对解码器做**2000次AdamW更新**，batch16、lr0.0005、seed2313。450 Train重建Dice均值0.9179→0.9344，p5 0.7725→0.8077，无空白，通过预登记表示门槛。每张重建都读取真实目标，不能冒充生成。
3. 由作者略偏好的v01012 A权重初始化新的**469842参数**生成器，冻结适配后的Codec。新增共享32维个人参数、64维字符表示、4头空间字符注意力；所有词使用同一共享参数，不逐词输入目标照片或风格参考扫描。字体图只作内容条件，最终像素由神经解码器输出，没有字体复制或几何形变的输出捷径。
4. **8000次新AdamW更新**，batch16、lr0.0002、seed2313；按词标签均匀抽样，再抽真实变体，450样本全部实际参与。15%样本屏蔽字体空间条件、2%纯噪声端点、前景加权v损失＋0.15真实墨迹基础重建损失。保留初始参数、优化器、RNG、每1000步checkpoint和训练曲线。
5. 固定最终8000步权重再评估，没有按开发集挑checkpoint。旧24词、58开发词、12未出现于任何原Train标签的新词，共94项×两个种子，64步采样。随机噪声决定个体变化，个人参数固定。验证和新词没有进入优化器；新词零目标数组仅为结构占位，禁止算重建或训练数据。

共享参数是全词共用的可学习偏置；单作者训练中，它可以与网络其他参数互相吸收，**本身不证明风格与文字已经分离**。用户要求的“稳定个人风格”必须体现在多种新文字的可读输出中，而不能靠参数名字证明。

## 不足的原因：已定位与尚未证明分开

**表示能保留墨迹，生成文字身份仍失稳。** 冻结模型在450 Train的零更新噪声分层诊断中，单步去噪Dice在t=.10/.25/.50/.75/1.0为0.9305/0.9159/0.8755/0.7886/0.5772。低噪声时目标信息仍在，重建清楚；高噪声时必须靠文字条件重建，质量变差。64步纯噪声生成进一步出现失真，支持后续检查高噪声条件学习与采样误差累积。单步和多步任务不同，这组数字不是某一因果机制的最终证明。

**注意力和共享个人参数有实际影响，但没有学对。** 同seed关闭共享个人分支，输出平均绝对变化0.01767；关闭新增空间注意力为0.02843；去掉字体空间码为0.08739（像素0–1）。关闭空间注意力仍保留旧全局文字条件，不能称“完全无文字”。这些是冻结后的机制诊断，不能等同等预算重训消融，也不能据它们认定哪个模块独立造成退步。

**扩大任务时同时改变了多个因素。** 数据从24词/19标签到450词/282标签，同时改架构、解码器、损失、采样平衡及字体条件dropout；本轮不能把退步唯一归咎于任何一项。74.8%的词仅一个实例，缺少同词多写法监督，限制了“哪些变化仍保留字符身份”的学习。但没有新证据证明标签错误是主因，也不能简单说再加PDF或再跑8000步一定有效。

**训练收敛与风格稳定不能画等号。** 训练损失下降、权重改变、两个种子差异增大，都不代表词能读对。RTX5060本轮生成器峰值Torch分配约0.86GiB，没有显存不足或OOM；当前证据不支持先换显卡。个人风格应从跨内容的共同规律学到，不能把一个固定向量或更大随机扰动当成果。

## Go / No-Go与下一步

- **No-Go：** 本轮新模型进入整页作业、替换旧候选/默认Profile、同配置继续加步数、打开C、整句扩大训练或RL。当前不需要作者评失败图或再导出评分。
- **Go：** 保留新解码器为真实墨迹表示的候选，保留全部失败权重和数据；下一有限实验先验证文字身份与空间墨迹对应，之后才讨论个人风格变化。
- 下一轮应先固定Codec、数据和训练预算，用16–32个清楚真实词做高噪声条件能力诊断；明确空间文字条件能否在**不读取目标**时保持完整字母，再逐步扩词。先分别考察字体条件dropout、注意力和高噪声训练分布，不同时改全部因素；不以小集记忆通过宣称泛化。
- 复用现有真实数据中重复字母组合和同词多写法，保留词/片段上下文，不强切连笔；只在内容通过后检验不同词是否共享粗细、倾斜、比例和节奏。可审计的340个非目标同页参考配对暂未输入训练，不能称已经学会参考无关风格编码。
- 当前12新词已经曝光，只能作为开发回归；未来独立判断仍需冻结候选后使用未打开的C。暂不需要作者新增PDF；如后续确需某些重复片段，再列具体缺口，不让作者从头抄字母表。
