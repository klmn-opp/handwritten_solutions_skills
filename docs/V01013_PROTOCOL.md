# v0.10.13：跨词的稳定个人风格与内容泛化

作者反馈：两seed、A/B均无明显区别，A略优；模仿本人程度较高，但希望稳定、可生成新词的个人神经风格。替代上一轮seed2012略优的暂定偏好，不把反馈变成内容通过或默认发布许可。

## 新假设与固定范围

旧模型推理不读取目标照片，但仅24词/19标签容量训练不足以证明跨词风格。新架构共享一个可学习个人向量，所有词使用同一向量；局部字符通过真实神经cross-attention与空间墨迹交互，而不再只叠加弱投影。单作者数据无法独立辨识“作者因子”，向量更新本身不是学会风格的证据，必须看未见文字与内容通过后的可视结果。

已审核原数据613视图中，选ASCII纯英文2–18字符：450Train、58旧文档级开发。Train和开发源文档分离，无新增识别或改标签。旧开发已曝光，不能称全新Holdout。C永不用于图像/识别/训练。
340个Train目标有同一真实行内、不同文字、间隔至少4px的非目标参考候选，但本轮**不把它们逐词作为输入**，避免输出风格随选中参考跳变。先训练固定共享个人向量；此向量无法靠自身证明语义风格分离。

## 预登记预算与检查

1. 旧Codec在450Train的零更新重建均值0.9179，p5为0.7725。保持编码器冻结，仅适配解码器2000次AdamW更新，batch16、lr0.0005、seed2313。要求Train平均Dice>=0.93、p5>=0.80、无空白，才能进入生成阶段；目标依赖重建不算生成。
2. 生成器由作者略偏好的v01012 A warmstart，冻结新Codec；保留原空间码归一化以兼容旧编码器。增加共享32维个人参数、64维局部token embedding及4头cross-attention、软位置偏置。每个输出像素仍经神经解码，无字体复制/形变输出通道。
3. 固定8000次新AdamW更新，batch16、lr0.0002、seed2313；均匀抽词标签，再抽其真实变体。仅450Train；字体仅条件，15%批样本去掉字体空间条件以检查文本依赖；2%纯噪声端点，其余连续噪声。前景v损失＋0.15基础真实墨迹重建损失，不继续增大向配对像素收缩的细节损失。固定最后checkpoint，不按开发集选择。
4. 冻结后输出旧24词回归、58旧文档开发和12从未出现在任何原Train标签中的固定词：coherent、consistent、handwriting、reasoning、variation、solution、integrate、function、smooth、student、vector、matrix。每项seed2012/2013、64步；不能因失败删词。
5. 新词12×2匿名Sol内容检查，旧前12×2回归检查。新词>=20/24完整且精确、无空白/严重缺损，历史回归不低于旧11/24，仅允许继续研究验证，不直接生产。旧门槛失败记录不改写成通过；本轮新问题是未见词泛化。未通过不追加当前配置步数。
6. 生成时共享个人向量固定，分别做关闭风格/文字交互/字体条件的零更新诊断；量化真实Train最近邻、两个seed差异、笔画统计与空白/边界。只能把它们当机制/稳定性代理，不能替代作者自然度判断，也不能凭“无二值复制”排除记忆。

总新增参数更新上限10000。目标文本输入、非目标字体条件、随机噪声、真实目标监督严格区分。所有split、权重/优化器/RNG、初始状态、原图/失败图、训练曲线与源码commit、依赖、设备信息留存。
不上传个人数据，不更换CPU/Profile/latest，不训练数学、不做RL，不恢复暂停的第三方模型路线。未过内容检查的模型不用于正式作业；研究对照可展示失败并明确标记。
