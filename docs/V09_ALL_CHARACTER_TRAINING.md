# 全部个人字符联合训练

本实验承接 `9200793`，在独立分支 `experiment/all-personal-glyphs-v09` 实施。
用户授权全字符实验候选，不代表发布或更改默认 Profile。

## 冻结方法

原有个人字库覆盖75字符、178轮廓。它们是字体派生监督，不能计作新增真实扫描。
旧辅助导出误排句号和逗号，本轮在独立96像素视图中保留这4个自然小轮廓。
按原始字符尺度/基线渲染；必要时整体等比适配，不裁掉下伸结构。
真实训练仍仅使用通过既有来源与标签准入的单字符裁剪，原文档分组不变。
允许稀疏类别进入本轮实验；旧20/5/5门槛未达标仍须报告，不能宣称生产合格。

旧CVAE只依赖标签和潜变量，非目标字形失败。新 `reference-sdf-cvae/1` 接收
真实个人字体的基准轮廓、字符标签及随机变量，卷积解码器预测完整距离场。
没有直接像素复制、轮廓选择或坐标抖动的输出路径。参考特征经学习网络处理，
后验和参考条件先验通过KL约束联训，距离场到墨迹的边缘规则在训练/推理一致。
这是新小模型的参数训练，不能称为不兼容旧CVAE的直接续训；仅支持单作者离线单字。

初始阶段4000次AdamW更新，32批量，28个按类别均衡字体样本+4个按类别均衡真实样本。
精确字符表在每次数据run的manifest和coverage中。
每250次记录开发集诊断，1000次后按冻结代理评分保存最优模型。
模板匹配仅用于开发诊断，不是独立识字正确率。允许根据Train/Validation失败继续有界训练；
新Holdout在候选冻结后才打开，不能用于调参或选择权重。

## 复现入口

CPU协调器：`PYTHONPATH=.:src .venv/bin/python -m research.corpus.reference_study prepare DATASET`

CUDA训练：`PYTHONPATH=.:src .venv/bin/python -m research.corpus.reference_study train DATA_RUN/reports/data`

可选 `--steps 4000 --seed 1909 --resume PRIOR_RUN --learning-rate 0.0001`。
resume保留已学习权重和优化器，单独run记录来源摘要；重新固定采样种子，
不是原始进程逐位续跑。PyTorch只在独立环境导入，生产Runtime没有新增依赖。

所有数据、checkpoint、曲线、预览均在不可复用run中；不修改latest指针。
最后必须报告每字符来源、失败、多样性、记忆及独立样本覆盖，不能仅凭全类出图宣布成功。

### 固定600图的开发诊断

每类8次先验生成，seed2909。首轮与最终统一比较：

| 指标 | 首轮best | 最终候选 |
|---|---:|---:|
| 个人字体变体匹配代理 | 97.67% | 99.5% |
| 空白 / 边界越界 | 0 / 0 | 0 / 0 |
| 额外连通分量的断裂代理 | 13/600 | 6/600 |
| 与已有字体二值轮廓完全相同 | 10/600 | 11/600 |
| 平均二值墨迹差异低于2%的类别 | 0 | C、m |

这不是OCR正确率。最终`1、4、6`各有一个模板归类不一致；`5、S、c、f、p`有断裂代理标记，
其他弱笔/断笔也可能漏检。11个二值相同结果主要是逗号、点、短线等简单形状；
其余像素不同也不等于已证明合理新字形或没有记忆。模型没有直接复制输出的代码路径，
但有限字体监督仍有记忆、变化不足和中间形状失真的风险。

### 冻结后的独立真实样本

先冻结最终候选和第一轮对照，才打开phy1新30个Holdout；此后没有训练、换权重或选择种子。
统一按参考范围整体等比对齐，距离越低越接近这批裁剪：

| 方法 | 新Validation30 | 新Holdout30 |
|---|---:|---:|
| 字体已有变体中最佳（每类2–4） | 0.15882 | 0.18695 |
| 非学习几何扰动8选1 | 0.15489 | 0.17357 |
| 首轮神经8选1 | 0.15117 | 0.17630 |
| 最终神经8选1 | 0.15177 | 0.18209 |

最终候选断裂代理更少，但Holdout形状距离比首轮差；没有根据此结果回退挑选权重。
神经未胜几何基线。每类Holdout仅1条，且字体候选数量不同，不能把此表当独立识字准确率、
自然度、作者相似度或有统计把握的优胜结论。对齐抹去了部分大小/位置差异，未验证单词节奏。

### 冻结后无标签内容盲检

从最终固定输出每类取第0/4个样本，共150图，用固定seed3911随机排序并隐藏目标标签。
用户授权的Sol xhigh只读取无标签图与数字编号，不读取目标映射，逐项保留转写/备选/置信度/缺陷。
该过程是模型目视评估，不是人工真值或作者风格评分；没有将生成图改标为本人真实训练数据。

- legible120、ambiguous22、damaged8；125项给出转写，25项保留null。
- 125个非空转写中120个与目标相同，5个不一致：`√→T`两次、`5→J`两次、`o→σ`一次。
  高置信且legible71项中69项匹配；未识别项不能静默删掉后宣称总体正确率。
- 缺陷涉及O、2、+、G、4、d；与连通分量代理并不重合，说明简单图像指标漏掉了视觉问题。
- 孤立0/O/o、1/l/I、点号和横线缺少语境时主动弃答，不把所有弃答认定为真实文本错误。
- 99.5%模板代理没有捕捉这些内容歧义；个人字体参考本身的可混淆写法也可能被模型继承。

证据：`20261118T171401676854Z-all-character-blind-content-7e5736c0`，内含150无标签图、
Sol原始逐项判断与封存后的评分；主交付`blind-result.json`可见计数及不匹配清单。
