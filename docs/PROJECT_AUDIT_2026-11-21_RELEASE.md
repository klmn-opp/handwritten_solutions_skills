## 3. 当前实际使用的方法

### 3.1 发行 CPU 路径

`src/hwsol/jobs/runtime.py` 管理通用 Job、Profile、输出与状态。默认 `font-cpu` 使用可靠字体路径；若 Profile 含个人墨迹资产，必须经过资格验证并满足其已审核渲染配置，才能由 `PersonalCpuEngine` 进入普通 CPU 出稿。`personal-cpu-experimental` 是隔离实验入口，不等同于正式准入。

`src/hwsol/personal_ink/runtime.py` 运行经过验证的个人数学字形与几何规则。其主要组成是：

1. 保存来源的真实个人轮廓、字形变体和必要的结构笔画配方。
2. Handnote / MathText 解析公式并确定分数、上下标、根式、矩阵、括号的二维结构。
3. Resolver 在可用时选择已核验个人素材；允许的拉伸和结构绘制有独立来源类别。
4. 输出逐项字形来源、字体回退、结构笔画以及边界与接触检查记录。
5. 缺失素材或不支持的结构必须显式回退或拒绝，不能靠自由图像生成补全数学内容。

这是**确定性字体、真实墨迹与结构排版的混合 CPU 系统**。字形采集、轮廓提取、尺寸修正、墨色校准和词距调整不是神经网络训练。本轮认可候选保留了 192 项墨迹/字体资产，词距调整没有替换这些字形。

普通 CPU 运行不强制依赖 Torch、CUDA 或研究脚本；也不依赖预先为特定题目生成的单词图片缓存。公开包可用已许可的 Patrick Hand 字体直接出稿，个人 Profile 可独立导入。公开字体示例的外观不能用作“已包含作者私人字形”的承诺。

### 3.2 保留的最佳英文神经研究骨干

实际源码：`research/corpus/canonical_ink_model.py`。架构名 `canonical-conditioned-ink/1`，参数量 194,513，输出 96×96 局部墨迹强度图。

模型输入为字符身份、8 维局部形态条件和共享的 8 维作者表示。字符嵌入为 16 维；拼接条件经小型全连接层形成 6×6 特征图，再通过四级上采样卷积及作者条件调制生成墨迹。它不是扩散模型，也不是直接输入整词图像的连续书写网络。

实际 checkpoint：

`workspace/runs/20261120T022439649806Z-canonical-ink-component-refinement-fbea19c9/logs/checkpoint-01000.pt`

SHA256：`779a2ab51902a17a7068df2c32bf7f5ceddef938ee6982f116f39e0dfb3ad15d`。本次读取实际文件后与注册表一致。

其可靠真人监督为 275 个字形视图、28 类真实字符；另外 44 类有字体辅助。275 是视图数，不等于 275 个独立来源。常用采样从同类已见形态中心出发，再加入约 `0.15 × 类内标准差` 的扰动。因此局部重建和条件采样成功，不能直接证明完全独立的未见词连续生成。

v0.10.22 的主要有效改善来自 t/l/r 等几何校正，v0.10.23 来自测量后的词距。它们没有替换 v0.10.21 主力网络。旧七页 D 中前四页有 526 个冻结神经词图，另有 13 个 Handnote 组；补充三页主要使用 CPU 英文。v0.10.24–26 数学修订复用了旧神经词图，没有重新训练或重新生成整套英文。

这个研究骨干被完整保留作未来对照，但没有随当前 CPU 发行包成为强制模型，也没有被描述为已经学会整词连笔。

## 4. 历史路线与结果

详细历史依据为 [retrospective.md](../workspace/analysis/20261120-font-method-retrospective/retrospective.md)；下表保留方法差异，避免重复失败路线或以改名冒充进展。

| 实际尝试 | 结果与现有定位 |
| --- | --- |
| 静态个人字体、GSUB 变体、统计布局 | 可靠 CPU 基础；属于资产与布局方法 |
| 六动作 gradient bandit | 调整预设动作选择；不是神经生成器强化学习 |
| DiffInk、DiffBrush、DiffusionPen | 有条件推理/冒烟研究；没有完成个人模型监督微调并进入生产 |
| 单字/整词 CVAE、SDF、墨迹场与轮廓损失 | 局部重建可用，但独立采样的内容、缺笔或形态稳定性不足 |
| Flow、单调几何变换、字体约束 | 可控制形变；强约束压缩变化，弱约束损害字符身份 |
| GAN、局部扩散、潜空间去噪 | 保留实验与失败证据；没有证明新内容整页收益足以替换骨干 |
| 字符身份/坐标条件、共享风格、分层先验 | 帮助分离内容与风格，但先验或重建指标并不等于自然生成 |
| v0.10.21 局部规范化神经墨迹 | 当前最有效英文神经研究基线；覆盖与连续性仍有限 |
| 真实数学原迹、个人 Resolver、结构笔画校正 | 对实际页面产生有效改善；成为当前 CPU 候选核心 |
| 上下文残差/对齐小试验 | 已形成 No-Go；16 组冻结 A/B0 比较、16 段原色对齐，32 次真实 GPU 前向、0 次参数更新；没有伪造 C 训练结果 |

共同经验：重建与新内容生成分别验收；训练损失、模型大小、运行次数都不代表成品进步。连续监督必须来自真实词、行及连字，不能把字符组合重新命名为连续模型。尚未进行可证明的神经生成器 DPO/RL，也没有理由用 RL 修复当前内容可靠性不足。

## 6. 明确的限制与未完成事项

- 数学覆盖不是无限的。压力测试仍有 ℤ 的真实个人来源缺口、密集 Φ 放置约束；不支持的宏或结构应拒绝或清楚记录回退。
- 新概率页的高根号钩部略弱但仍可辨认；应作为后续检查项保留，不能因自动门禁通过而隐去。
- Linux 使用 RAQM，Mac 使用 BASIC；同为 Pillow 13 / FreeType 2.14.3，文字位置和变体选择仍有跨平台差异。同平台两 Python 输出一致，不承诺跨平台像素完全一致。当前差异经页面复核未确认造成数学、内容或边界错误。
- 作者批准的是具体页面与限定词距调整；不是任意未来符号或任意新模型的预先视觉批准。
- 原 M1 Holdout 7/8 已消费并出现修复流程，不能再用修复后重跑宣称全新独立泛化。封存 C 不因发行而开启。
- 当前完成的是 Linux/macOS 支持范围；没有实际证明 Windows、任意 LaTeX 或所有复杂课程题目均支持。
- 上传成功、公开源码完整性及稳定包最终哈希要以最终发行回执确认。本审计不将“正在准备”写成“已经上线”。
