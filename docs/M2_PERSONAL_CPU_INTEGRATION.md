# M2 — portable personal CPU candidate

The author broadly accepts the Session O output and authorizes continued development.
This increment tests whether the accepted handwriting and placement can be used from
an ordinary, explicit Job through an installed CPU package, without research modules,
page-index dispatch or precomputed problem-specific images.

Production/default/latest are not promoted. There is no neural parameter update.
This is product integration and faithful source reuse. The frozen v21 neural backbone
and v23 mixed-page English experiments remain distinct from this CPU path.

## Mechanism

`personal-cpu-experimental` requires a version-pinned inactive candidate Profile.
A data-only recipe inventories nested font Profiles, approved original glyph crops,
historical components, structural stroke sources and authentic f variants. Every live
path stays within the Profile with matching SHA; historical PDF paths remain provenance
metadata and are never runtime dependencies. Different fonts cannot reuse this font's
calibration merely by changing a filename. Source roles must have accepted originals.

The ordered deterministic recipe applies existing Latin/digit metrics, mathematical
sources, radical clearance, real structural strokes and f variants to normal parsed
Handnote/MathText slots. No per-page number branches, formula-specific bitmap cache,
freeform image generation or content rewriting. Geometry/source/parser checks run on
actual placed outlines before accepted PDF output. Unsupported parsing/overflow fails
explicitly; an unsafe individual source substitution retains the prior glyph, with its
source and refusal reason visible. This separation prevents a local style problem from
silently deleting a mathematical symbol or invalidating an otherwise readable formula.

Successful candidate Jobs remain `held`, never updating latest even when a caller
requests the usual latest behavior. CLI import/export preserves inactive candidate
identity; activation and ordinary Studio publication reject this experimental recipe.
The default font-cpu backend and bundled default stay available.

## Scope and unresolved gates

This is a qualified opt-in local candidate, not v1.0 publication. Arbitrary formulas
are not guaranteed: ell, widehat and matrix-spanning braces remain explicit refusals;
missing source roles and unsafe placement retain documented font fallbacks. Seven
old procedural short radical roofs in the original24 remain unchanged. Known older
held f glyphs are preserved. No new continuous neural English generation is claimed.

Linux installed-wheel and macOS are separate evidence. Actual macOS runtime validation
cannot be inferred from Linux or universal-wheel metadata. The author's broad current
satisfaction is not a formal blind comparison or authorization to activate production.
The M4 context-residual hypothesis and RL remain No-Go under their own existing reports.
