# v0.10.5 新连续材料：预注册有限实验

用户新增A/B各1页、C1页与数学配对6页。A/B真实转写由授权Sol xhigh保守验收，不用印刷提示代替。
C整个原件封存，开发与调参不渲染、不读取；数学独立标注，不自由生成数学结构。
旧数据与新版数据并行保留，旧文档Validation仍仅开发参考。

## 新假设与局限

旧自由像素输出把难以对齐的笔画平均成灰影；本轮试验真实监督的窄范围轮廓修正，参考来自personal@v1。
输入整块参考距离场，卷积网络输出上下文相关的轮廓距离修正，128x1024原生视图；每处最多2.5像素，远背景不改变。
最终0.35像素边界转换固化于模型定义，零更新参考距离场另列，不能把这种转换算学习收益。
这是**字体约束的学习式轮廓修正组件**，强先验限制拓扑，不宣称自由整句生成、真实在线轨迹或随机个人变化。
它可能只逼近原字体；须报告到字体距离、实际改变及真实验证拟合，不能仅以灰影少判成功。

## 固定两臂

local / context：相同初始化种子1501、真实数据、batch4、1500更新、AdamW lr0.0003。
context通过沿行卷积引入相邻词和整行信息，local禁用该路径。公平保留相同初始化，local冻结未用层。
不混字体作真实目标；新A/B行采样概率35%，余下旧真实Train65%，实际独立样本数不膨胀。
目标是实际扫描形成的轮廓/墨迹，损失contour + .3Dice + .15细笔支持 + .01空间平滑。
无OCR教师参与新训练，冻结TrOCR作为识别观察，仍不能把OCR差异当真实错误。
每500步保留模型、优化器、RNG和曲线，固定最后一步。C不用于模型选择。

## 门禁与后续

首先检查新真实样本的原图、边界与对齐准入。候选需无空白/裁切；模型盲转写不得较Handnote增加明确漏字替换，灰影下降且不产生粘连/断笔。
开发集选择固定的长行/短词对照，不只用形状距离。
候选冻结且开发内容可用后才开启C；若开发已失败，C继续封存，先修方案。
内容通过后需要作者判断自然度/本人风格是否优于原字体，这可作为本阶段手动节点；未通过不发布。
数学先交付来源可追溯的真实公式/LaTeX对照，可靠解析器控制数学结构，不用英文模型替换公式。
所有新run保留权重摘要、原件、来源提交和环境；CPU Runtime/Profile/latest不改。
