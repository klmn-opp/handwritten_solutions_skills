# v0.10.2 去灰影固定试验协议

承接6a83567，用户认可v0101 aligned-content文字成型，要求消除背景灰影/重影且保留笔画。
生产CPU、Profile、latest和旧run不变。已有21测试区域仅历史对照，Sol另封未用区域。

开发诊断：同171 Train，真实目标平均墨量1132.8，旧输出2569.3；>.1可见墨迹中软像素
（.1–.9）真实约68.39%，旧输出98.97%。原始生成图已有灰影，不是PDF才产生。
固定logit×3和原等值轮廓重建为零参数更新诊断；二者保持>.5二值轮廓，不可称神经训练。
它们能压灰，却不能自动修复原二值轮廓内的粘连。

预先固定三个学习方案；都从用户认可的v0101 aligned-content最终checkpoint开始，
使用同一171真实Train与25Val、不新增/重标真实标签，seed1203、AdamW lr .0001、batch4每批3真实1字体，
各1500次更新，固定最终步。重新创建优化器是新目标微调，不冒充旧优化器的精确恢复。

1. control：原有SDF/BCE/Dice及每4步.15×冻结TrOCR内容约束，检查单纯续训。
2. distance：原目标+1.0×距离场自一致约束。将当前预测的零等值轮廓重新计算距离场并停止梯度，
   约束预测具有正常空间过渡，减少大面积半透明区域；这是正则辅助，不是新真实标签，也不是字体回填。
3. mass：distance+0.15×相对墨量误差；真实或字体辅助目标分别提供自己的墨量，禁止看新测试目标。
   内容约束同时看原输出与固定logit×3输出，二者CE取均值，避免仅在半透明图中藏文字。计算量不等于其他臂。

网络架构、SDF→墨迹的默认转换不变。所有新学习输出保留原始浮点/PNG，不偷偷用显示锐化替换。
最终并列显示Handnote、本人参考、上一轮原输出、上一轮仅显示锐化及三个新训练结果。
不通过单一灰度统计选择模型；纯白图、丢点、断笔不能作为去灰成功。内容观察优先，随后比较灰影/墨量/断裂与作者自然度。
旧TrOCR是训练教师，只用于非独立诊断；另用Tesseract和Sol匿名转写及原图，作者最终评审不由模型代填。

所有候选冻结后才打开新区域；无新文档时明确fresh_document=false。冻结后不再训练或挑checkpoint。
保存初始状态/每500步权重与优化器/RNG/曲线/依赖/硬件/源码/标签和教师摘要。
训练在隔离CUDA环境；长任务使用有PID、日志和终态记录的监督进程，交付前确认结束。
任何模型均不替换数学或正式Runtime。本轮不训练随机风格/自由行距，不进行RL。
