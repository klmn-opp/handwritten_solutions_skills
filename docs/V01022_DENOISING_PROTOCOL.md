# v0.10.22 局部风格去噪先验实验

分层 CVAE 在随机推理时仍会产生断笔。固定清晰的 canonical balanced6k 墨迹解码器，
以已核验 PCA 风格坐标训练小型去噪网络。不同噪声强度下学习还原坐标，以逐步去噪代替
用单次前向从高斯潜变量推断字形变化。生成端从正态噪声开始，不查询训练中心或字形图。

沿用 60 个来源词训练组、8 个上游已经暴露的优化验证组，共 275 个可靠局部视图。
分组和全模型独立测试是两回事。冻住 PCA 的有效轴定义，验证组不参加参数优化。
每步每个训练覆盖类别均匀抽一个真实坐标，零轴不计损失。字符和左右邻字各用 8 维嵌入，
训练中以 50% 概率同时遮住两侧邻字。去噪器输入噪声坐标、身份、邻字和 log 噪声，
通过两层 96 维 SiLU 网络预测标准化残差。噪声标准差按 log 均匀采样 .03 到 4。
seed 4822，AdamW .001，2500 步，固定最终检查点，每 500 步记录权重、优化器、随机状态与验证。

评估同样的 24 词、8 行及 2012/2013 两种种子。24 个 log 间隔噪声值到 .03，
每个间隔作两次斜率修正，末尾再做一次去噪得到风格坐标。保留同布局的无邻字消融。
另用 8 种种子生成 28 类局部图，比较二值同形、同类样本最近邻和多样性。
空白、缺笔和身份歧义用于判定候选能否继续。这里更新风格先验参数，墨迹解码器冻结，
同类多样性从局部逐字采样产生，后续仍需完整词与行的连续性监督。
