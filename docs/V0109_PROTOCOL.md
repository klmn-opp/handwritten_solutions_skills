# v0109：真实形态学习与困难混排，有限实验协议

作者已认可v0108的清洁度及明显缺损修复，同时指出f等字形趋同，授权扩充数据和增加训练。本轮不把这条定性意见自动转成新评分、默认发布或开放C。

## 先固定的设计和预算

v0107/v0108只学习坐标场，输出墨迹仍来自现有字体。v09/v0106的直接CVAE又有内容失败及先验/后验差距。
本轮有限检验一个小型条件去噪网络：完整真实词或可靠片段的距离场作为监督，字体词图和完整ASCII序列仅作内容条件。
从独立高斯噪声出发预测像素，训练v参数化去噪目标；不存在复制字体的输出旁路，也不向字体形状加损失。
使用连续cosine alpha/sigma及64步确定性逆过程；参考[DDIM论文](https://arxiv.org/abs/2010.02502)，这是自建小原型，不是恢复DiffBrush/DiffusionPen/DiffInk研发或调用其权重。
本选择是针对已观察到的表示限制作的实验假设，未先验声称更适合或更自然。

1. 容量阶段：固定24条真实Train（先取前12个含f且长度2–10词，再固定种子补足），1000更新；仍是新模型真实学习，但不算泛化。
2. 只有容量样本无空白、平均二值Dice>=0.45且固定12词两种子视觉内容>=20/24匹配，才扩大数据。若1000未满足但有真实学习，允许一次固定再训练到累计3000步；失败则停止该原型，不重复同目标无限续训。
3. 扩充阶段：全部准入Train的完整词/片段，最多每8样本1个真实辅助f/F字形。容量权重可作warmstart，优化器显式重置。先3000更新；冻结后在开发集内容门禁>=90%且无严重缺损时，可继续到累计9000更新，否则保留No-Go。每1000步保留checkpoint，不靠单一形状分数挑最优。
4. 训练batch8、lr0.0003、seed1909；固定生成seed1910/1911、64逆步、128×512。无OCR训练教师；OCR/HTR只作独立观察，不能直接作真实错误率。
5. 所有步数表示真实optimizer更新。记录初始化、权重变化、优化器、RNG、源码/数据/配置摘要、曲线、GPU显存/耗时；每个阶段新run，旧权重完全保留。旧模型保持可回退。
