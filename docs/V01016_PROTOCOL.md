# v0.10.16 原始真实墨迹与一致的字符尺度

承接自主训练授权，v15主run与21子run已经封存。本阶段独立分支，CPU/Profile/latest/C和历史不变；训练环境仍为隔离Torch CUDA。目标仍是稳定个人神经笔迹，不以工程测试或像素距离冒充作者认可。

第一步固定18个原始词、89可靠位置标注、22真实字符类。只使用原裁剪统一缩放后的墨迹，无逆配准或合成补笔；源图、标签、字符位置均来自已审核Train。使用v15冻结24000步字体语义模型作内容初始化，4000次真实监督更新，seed3015、lr.0001、batch4、每图2048查询点，保持旧anchor-real其余配置以比较原始形状监督。推理仍只接收字符身份、邻接身份和布局框，不接收目标图或实测目标位置。

生成尺度由Train的真实宽高比中位数计算，保持Handnote给定的字高/中心/上下伸，不使用开发目标坐标。各类别的实例数和来源必须披露。两种推理对照：原字体框、Train统计框；统计调整为零更新后处理布局，不称神经训练。

如果未见真实类别发生遗忘，允许用冻结的字体辅助神经场作逐类显式回退，真实覆盖类别继续用新模型；这属于混合模型推理，不得虚报全部字母都来自真实扫描训练。首先保留真实完整原图自行检查明显灰影/缺损，再做盲化内容观察。通过内容才扩大句子/数学页面，旧数学基线不能冒充新模型。

并行复核剩余48个旧Train词的原始形状标注可行性，Sol只看实际墨迹与可信文字；输入隐藏字体元数据。不能可靠归属的连笔不拆分，仅不进入此定位子集，继续保留为完整词/行。新数据入集必须重新校验来源摘要、标注覆盖及Train边界。

每个后续实验须在运行前追加有限预算与因果理由。不得对失败配置无限加步数，不用作者筛明显失败图。旧开发重复曝光，只作开发检查；C继续封存。

## 第二步：区分确定性平均与后验编码瓶颈

原始18词4000更新无空白/越界，但毛边/灰芯仍在。剩余48原词复核无可安全逐字定位项（46明确连笔、2不确定）；不能强拆来扩大此子集。原图/整词标签全部保留。

有限词级auto-decoder对照：同18真实词、同24k起点、同4000次模型更新/采样/BCE+.2SDF。另优化每个Train词的2维变化码（AdamW .001，模型 .0001），.01码L2；码表只存在于训练状态，不在生成网络中。模型经2→16投影共享到词内全部字符。它确实训练神经参数，但不因为可重建就称形成风格分布。训练目标不使用字体图像。

冻结后，18词使用优化码/真实位置生成仅作重建容量诊断；另从Train码均值和协方差加1e-4对角拟合高斯，seed2012/2013分别抽一个跨全部词共享的变化码，18Train+12旧开发+12提示共84先验图。先验仅用文字和Train尺度校正布局，不能读取目标图/目标位置/对应训练码。记录协方差谱、先验/重建差、无字形复制检查；高斯是否适合18个码尚待验证。若先验仍有缺陷，不继续扩大同配置，不邀请作者猜失败图。

## 第三步：让网络看见实际尺度，而不只改变输出框

Auto-decoder完成4000：变化码确有学习更新，但先验和训练码重建仍有相似灰芯。原始目标干净，不能归咎扫描污染或仅后验编码器。检查现有神经场发现，它只接收各字独立归一化后的xy，却不接收实际字宽/高；不同笔画粗细和纵横比的真实变体可能被压到同条件。此前框校正只是改变显示几何，未向神经场提供该信息。

同18词/24k起点/seed3015/4000更新加入零初始化的2→32投影，输入log(宽/高)、log(高/48)，加到字符身份特征；保留其他损失与抽样。生成框只用Train统计，内容、旧框、真实框和原始笔形来源仍分开。这一实验检验尺度条件，不宣称随机笔迹训练。比较对象为raw-real＋相同Train尺度校正的零更新输出，不能把两个变化混作单因素收益。
