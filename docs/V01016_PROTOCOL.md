# v0.10.16 原始真实墨迹与一致的字符尺度

承接自主训练授权，v15主run与21子run已经封存。本阶段独立分支，CPU/Profile/latest/C和历史不变；训练环境仍为隔离Torch CUDA。目标仍是稳定个人神经笔迹，不以工程测试或像素距离冒充作者认可。

第一步固定18个原始词、89可靠位置标注、22真实字符类。只使用原裁剪统一缩放后的墨迹，无逆配准或合成补笔；源图、标签、字符位置均来自已审核Train。使用v15冻结24000步字体语义模型作内容初始化，4000次真实监督更新，seed3015、lr.0001、batch4、每图2048查询点，保持旧anchor-real其余配置以比较原始形状监督。推理仍只接收字符身份、邻接身份和布局框，不接收目标图或实测目标位置。

生成尺度由Train的真实宽高比中位数计算，保持Handnote给定的字高/中心/上下伸，不使用开发目标坐标。各类别的实例数和来源必须披露。两种推理对照：原字体框、Train统计框；统计调整为零更新后处理布局，不称神经训练。

如果未见真实类别发生遗忘，允许用冻结的字体辅助神经场作逐类显式回退，真实覆盖类别继续用新模型；这属于混合模型推理，不得虚报全部字母都来自真实扫描训练。首先保留真实完整原图自行检查明显灰影/缺损，再做盲化内容观察。通过内容才扩大句子/数学页面，旧数学基线不能冒充新模型。

并行复核剩余48个旧Train词的原始形状标注可行性，Sol只看实际墨迹与可信文字；输入隐藏字体元数据。不能可靠归属的连笔不拆分，仅不进入此定位子集，继续保留为完整词/行。新数据入集必须重新校验来源摘要、标注覆盖及Train边界。

每个后续实验须在运行前追加有限预算与因果理由。不得对失败配置无限加步数，不用作者筛明显失败图。旧开发重复曝光，只作开发检查；C继续封存。
