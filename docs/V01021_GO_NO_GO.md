## 内容观察，不能冒充正确率

本地真实TrOCR和Tesseract运行224图、448转写观察；识别请求不含目标文字。没有作为本解码器训练损失，属于独立识别器，但文本提示已反复曝光，**不是独立Holdout**。

TrOCR原始整行CER：Handnote .0245，5k .0286，两6k臂均.0232。大量差异来自HTR在句号前插入空格；孤立词还常幻觉尾标点。原始指标没有悄悄清洗，逐条输出保留。`smooth` seed2012被读作`smouth`、`initial`的个别seed有分歧，应继续核查笔形与组合，不能把这些数字直接算成真实文本错误率。Tesseract整行CER约.153–.166，不足以独立判断谁更自然。没有新的作者风格分数、人工真值CER/WER或独立C成绩。

## 决策

Go：以清晰的局部生成器为冻结基础，下一有限实验直接使用真实完整词，训练受约束的上下文修正；比较原始局部组合、上下文模型与去邻域对照。先审计18个强对齐完整词的初始误差及墨迹强度，防止把扫描弱墨/背景当作目标风格。
