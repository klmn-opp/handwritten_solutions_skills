# 七道复杂题：已验收的下一代样张

这两份 PDF 是作者视觉验收的七道复杂题，由冻结的 `nextgen-v1` 权重生成。
题目、解答与数值核验由宿主 Agent 完成；页面在隔离研究运行中渲染，使用固定
A/B 种子。v1.2.0 产品后端加载同一组权重和底字，但采样种子由当前 Job 派生，
因此新页面不会与这两份 PDF 逐像素相同。

| 文件 | 内容 |
| --- | --- |
| `complex-A.pdf` | 七页，种子 A |
| `complex-B.pdf` | 七页，种子 B |
| `page-05-preview.png` | A 组第 5 页的等比预览（50%） |

覆盖：极化介质球壳、两能级量子猝变、混合边界热方程、硬币偏置贝叶斯推断、
仿射代换密码、集合的像与原像、平面线性变换的谱。A 组包含 2,968 个英文字位、
866 个数学排版项，覆盖 52 个英文大小写字母与 102 个数学字形或结构标签。

页面中的英文与数学墨迹来自作者个人实写底字、冻结的有界形变和确定性墨量
校正；分数线、根号横线等结构由 CPU 排版绘制。原始扫描、裁剪和训练检查点
不随仓库发行。

来源运行与逐页校验值见 [provenance.json](provenance.json)。
