# 下一代默认生成后端

v1.2.2 起，干净安装使用作者个人 Profile 时，`hwsol render` 默认启用
**`personal-neural@1`**：稳定的个人 CPU 排版继续负责数学结构、字位和边界，
冻结的下一代字形模型负责英文字母与数学符号的有界变化。最终页仍经过确定性
墨量/灰度校正和整数词距处理。

这不是整页自由生成。公式语义、分数/根号/矩阵结构、换行和页面边界始终由
CPU 排版决定；模型只在已有字形槽位内改变形状。

## 组成

| 层 | 作用 | 是否学习 |
| --- | --- | --- |
| CPU 结构排版 | Markdown/LaTeX、数学结构、字位、基线、页面边界 | 否，固定 Handnote/MathText |
| 英文字形 | 粗形变 + 条件先验 + `f/t/h/r` 局部残差 | 是，冻结检查点 `5cfb0165` |
| 数学字形 | 9x9 位移场，按符号与用途条件化 | 是，冻结检查点 `757afef8` |
| 墨量与灰度 | 单位笔长墨量、前景深浅向同字号教师收敛 | 否，确定性规则 |
| 词距 | 词内间隙收紧，回收空间留给词间 | 否，整数像素平移 |

英文字形从 951 枚已审实写底字中抽取；数学字形从 755 枚已审符号原迹中抽取。
只有推理所需的子集随包发行，原始扫描、完整训练语料、优化器状态和其他版本
权重都不发行。

## 不改变权重

发行包保存的是与原检查点逐元素相同的 float32 数组：

- 72 个数组全部逐字节一致；
- 两个原检查点的 SHA-256 记录在 `manifest.json`；
- 导出和推理过程不创建优化器，也不更新任何参数。

维护侧另有权重审计与前向对照记录：逐数组比较原检查点，并用相同潜变量比较
Torch 参考与产品 NumPy 输出。公开测试只依赖 NumPy，不要求安装 Torch。

## 运行时与回退

- 不需要 GPU、PyTorch 或联网下载模型。
- 白纸页面使用神经后端；横线、方格、点阵和图片/PDF 背景委托稳定 CPU 路径。
  作者预设的最终词距要求语义排版，因此这些背景目前会被明确拒绝，而不是静默
  改变已验收的间距。
- 未覆盖的符号、结构元素、拟合失败、身份识别不一致或新增笔画接触时，该字位
  保留稳定 CPU 字形，不会静默替换。
- 显式写入 `"backend": "font-cpu"` 可继续使用纯 CPU 路径。
- 非作者 Profile（包括 Patrick Hand、用户自建 Profile）默认保持 CPU 路径。

## 已验证范围

v1.2.2 的实际安装、出稿和回退验证范围为 **Linux x86_64 与 macOS Apple Silicon（arm64），Python 3.12 / 3.13**。
Windows 不在本版验证范围，作者预设的包内准入不会在未验证环境上自动启用。
