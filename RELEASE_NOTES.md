# Handwritten Solutions v1.1.0

Clean installations now use the author’s reviewed personal handwriting as `author-default@v1`. Existing explicitly selected defaults are retained. Patrick Hand remains available as `bundled-default@v1`.

The release contains the compiled CPU font and mathematical outlines, including the accepted word spacing. It excludes raw scans, crop images, private training materials and neural weights. This is CPU glyph rendering, not neural training.

Create your own Profile with the documented three-step template → reviewed scan build/preview → local publish workflow. PNG, JPEG and scanned PDF templates are supported.

Actual native acceptance passed on Linux x86_64 and macOS Apple Silicon with Python 3.12 and 3.13. Layout improvements and writing into original-PDF blank areas remain future work. Windows is not supported by this release.

Download the wheel for the CLI, the source archive for editable inputs and guides, or the Skill ZIP for your Agent. Checksums and exact public-source binding are attached.
