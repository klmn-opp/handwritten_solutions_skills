# Changelog

## 0.6.0 · 2026-11-18

- Introduce immutable workspace run receipts, atomic latest-deliverable pointers, archive indexes and legacy Profile/output compatibility.
- Add the fixed 60-case benchmark, separate reference rendering and Agent submissions, resource metrics, independent observations and real Tesseract evaluation.
- Fix MathText relation aliases and reject unauditable formula fallbacks clearly.
- Keep font-cpu default and neural models excluded from production pending real CUDA/content/style validation.

## 0.4.0 · 2026-11-18

- Preserve the audited realism implementation and bind outputs/releases to code, dependency, Profile, policy and seed identities.
- Add opt-in measured glyph normalization and correlated word scale; preserve raw assets and descenders.
- Record each visible glyph/structure source, reuse suitable personal strokes, and generate Handnote collection queues.
- Add role-based formula starts and equality-group constraints, candidate metric assets and trace-origin contracts.
- Keep neural line generation isolated and explicitly unvalidated; see [current acceptance and limits](docs/NEXT_STAGE_DEVELOPMENT.md).

## 0.3.0 · 2026-11-18

- Added pixel verification between each delivered PNG and its PDF page, and regression coverage for nested equations, rotated paper sizes and seeded real glyph alternates.
- Reused repeated outline measurements, checked white-paper visibility directly on the export, and isolated candidate font handles during Studio evaluation.
- Added CI for two Python versions on three operating systems. Added a fresh-environment wheel smoke test and packaging from a Git tag.
- Added a local research CLI with pinned DiffBrush and One-DM sampling adapters, DiffusionPen output import, blinded English transcription and style scoring. Production continues to use deterministic math.
- Linux test results, outstanding platform checks and the scope of the model experiments are recorded in the [implementation status](docs/IMPLEMENTATION_STATUS.md).

## 0.2.0 · imported baseline

- Agent Skill, one-problem-per-page Runtime and CPU Profile Studio, including versioned publication, replay, verification and editable solutions.
- Prior engineering evidence for Phases 0–2 is included in docs/evidence.
